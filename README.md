## ✨ ¿Qué es?

Roderich Launcher es la aplicación con la que la comunidad de **Roderich** juega su aventura de
**Minecraft con mods**: exploración, construcción y mucha comunidad.

Está pensado para que no tengas que preocuparte por nada técnico:

- 🎮 **Un solo botón para jugar.**
- 🔄 **Se actualiza solo.** Cuando hay una versión nueva, el launcher la descarga e instala por ti.
- 🌌 **Interfaz propia**, con noticias de la comunidad y estado del servidor.
- ⚙️ **Ajustes a tu medida:** memoria RAM, gráficos, resolución, shaders y más.
- 👤 **Cuentas:** inicia sesión con tu cuenta de Microsoft o crea un perfil en el launcher.

---

## 💻 Requisitos

| | |
|---|---|
| **Sistema** | Windows 10 u 11 (64 bits) |
| **Minecraft** | Minecraft Java Edition original, para entrar al servidor |
| **Memoria** | Recomendado 8 GB de RAM o más en tu equipo (el launcher te ayuda a elegir cuánta usar) |
| **Internet** | Necesaria para instalar y actualizar |

> ℹ️ No necesitas instalar Java: el launcher descarga la versión correcta por ti.

## 📥 Instalación

1. Entra a la sección [**Releases**](https://github.com/Force-Studios/launcher-update/releases/latest).
2. Descarga el archivo **`Roderich-Launcher-Setup.exe`**.
3. Ábrelo y sigue los pasos del instalador.
4. Inicia sesión y pulsa **JUGAR**.

> 🛡️ **Si Windows muestra "Windows protegió tu PC":** es un aviso normal en programas nuevos
> que aún no tienen firma digital. Pulsa **Más información** y luego **Ejecutar de todas formas**.
> Descarga siempre el launcher desde este repositorio o desde los enlaces oficiales de Roderich.

---

## 🔄 Actualizaciones

Cada vez que abres el launcher, este revisa si hay una versión nueva:

- Si la hay, la **descarga y se reinicia solo**. No tienes que volver a instalar nada.
- Si no tienes internet, entra igual y sigue funcionando.
- **Tus cuentas y ajustes se conservan** al actualizar.

Puedes revisar manualmente en **Ajustes → Lanzador → Buscar actualizaciones**.
